# Reference game fixture

`src/reference-game.ts` holds a small deterministic game shared by domain, web, and API tests. It replays the six-play series from the "Examples" section of the [prototype football profile](../../docs/technical/prototype-football-profile.md), then corrects the last play.

The expected snapshots are written by hand and must never be generated by the engine they check. This page restates them for independent review: every value below must match `reference-game.ts`.

## Setup

| Item              | Value                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------- |
| Game              | `ref-game`                                                                            |
| Home              | `ref-home` (Reference Home): #7 `home-7`, #22 `home-22`, #81 `home-81`, #85 `home-85` |
| Away              | `ref-away` (Reference Away): #1 `away-1`, #12 `away-12`, #55 `away-55`                |
| Not on any roster | #33                                                                                   |
| Starting context  | Home in possession at own 25                                                          |
| Versions          | Ruleset `prototype-tackle/0.1.0`, statistical policy `prototype-rush-pass/0.1.0`      |

All plays are in period 1, with home in possession at the snap. Order keys are `0100` to `0600`.

## Narrative

1. **`ref-play-1`:** #22 runs for 4 yards.
2. **`ref-play-2`:** #7 completes a 27-yard pass to #81 for a first down.
3. **`ref-play-3`:** #7 throws incomplete, targeting #81.
4. **`ref-play-4`:** a runner seen as #33, who is on no roster, loses 3 yards. The play is recorded with an unknown ball carrier and observed jersey 33, marked `needs_details` and `needs_review`, and raises an `unresolved_identity` issue.
5. **`ref-play-5`:** #7 completes a 9-yard pass to #85.
6. **`ref-play-6`, revision 1:** #22 runs for 2 yards on 4th & 4. The ball is short of the line to gain, so the away team takes over on downs. This is not counted as a turnover.

**Correction.** Revision 2 of `ref-play-6` records the same run as 4 yards. Revision 1 stays in the history. The run now reaches the line to gain, so the home team keeps the ball with a new series and earns a rushing first down.

Plays 1–5 are `complete` and `confirmed` except play 4. Both revisions of play 6 are `complete` and `confirmed`.
